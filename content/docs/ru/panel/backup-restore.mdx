# Руководство по резервному копированию и восстановлению

PasarGuard включает в себя управляющий скрипт (`pasarguard.sh`), который автоматизирует резервное копирование базы данных, восстановление, обновление служб и обслуживание системы.

---

## 💾 Резервное копирование PasarGuard

Регулярные резервные копии гарантируют сохранность ваших учетных записей пользователей, настроек и параметров администратора при миграции сервера или сбоях системы.

### 1. Команда ручного резервного копирования

Чтобы запустить немедленное резервное копирование:

```bash
sudo pasarguard backup
```

Эта команда создает сжатый архив, содержащий:
- **Дамп базы данных**: Полный экспорт вашей базы данных (SQLite, MySQL, MariaDB, PostgreSQL или TimescaleDB).
- **Файл конфигурации**: Копию файла `/opt/pasarguard/.env`.
- **SSL-сертификаты и ключи**: Соответствующие учетные данные безопасности.

Резервные копии сохраняются по адресу:
```
/var/lib/pasarguard/backups/
```

---

## 🔄 Восстановление PasarGuard

Чтобы восстановить базу данных PasarGuard из ранее созданного файла резервной копии:

```bash
sudo pasarguard restore /path/to/backup-file.tar.gz
```

### Процесс восстановления

1. **Остановите службы панели**:
   ```bash
   sudo pasarguard down
   ```
2. **Выполните восстановление**:
   ```bash
   sudo pasarguard restore /var/lib/pasarguard/backups/pasarguard-backup-YYYY-MM-DD.tar.gz
   ```
3. **Перезапустите службы**:
   ```bash
   sudo pasarguard restart
   ```
4. **Проверьте статус системы**:
   ```bash
   sudo pasarguard status
   ```

## 🛠️ Справочник команд скрипта (`pasarguard.sh`)

| Команда | Описание |
| :--- | :--- |
| `pasarguard up` | Запускает все контейнеры Docker |
| `pasarguard down` | Останавливает все контейнеры Docker |
| `pasarguard restart` | Перезапускает все службы PasarGuard |
| `pasarguard status` | Отображает статус контейнеров |
| `pasarguard logs` | Просмотр логов системы |
| `pasarguard update` | Обновляет панель PasarGuard до последней версии |
| `pasarguard tui` | Открывает интерактивное TUI-меню |
