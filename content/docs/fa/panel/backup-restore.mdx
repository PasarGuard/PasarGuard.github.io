# راهنمای پشتیبان‌گیری و بازیابی

پنل PasarGuard شامل یک اسکریپت مدیریت کامل (`pasarguard.sh`) است که فرآیند پشتیبان‌گیری از دیتابیس، بازیابی، بروزرسانی سرویس‌ها و نگهداری سیستم را خودکار می‌کند.

---

## 💾 پشتیبان‌گیری از PasarGuard

پشتیبان‌گیری منظم باعث می‌شود حساب‌های کاربران، پیکربندی‌ها و تنظیمات مدیران هنگام انتقال سرور یا بروز خطا امن باقی بمانند.

### ۱. دستور پشتیبان‌گیری دستی

برای اجرای پشتیبان‌گیری فوری از نصب PasarGuard خود:

```bash
sudo pasarguard backup
```

این دستور یک فایل فشرده شامل موارد زیر ایجاد می‌کند:
- **خروجی دیتابیس**: خروجی کامل دیتابیس (SQLite، MySQL، MariaDB، PostgreSQL یا TimescaleDB).
- **تنظیمات محیطی**: کپی از فایل پیکربندی `/opt/pasarguard/.env`.
- **گواهی‌های SSL و کلیدها**: کلیدهای امنیتی مربوطه.

فایل‌های پشتیبان در مسیر زیر ذخیره می‌شوند:
```
/var/lib/pasarguard/backups/
```

### ۲. پشتیبان‌گیری خودکار

می‌توانید پشتیبان‌گیری روزانه یا هفتگی را با استفاده از `cron` خودکار کنید. برای زمان‌بندی پشتیبان‌گیری روزانه در ساعت ۳:۰۰ صبح:

```bash
(crontab -l 2>/dev/null; echo "0 3 * * * sudo pasarguard backup > /dev/null 2>&1") | crontab -
```

---

## 🔄 بازیابی PasarGuard

برای بازیابی دیتابیس PasarGuard از یک فایل پشتیبان قبلی:

```bash
sudo pasarguard restore /path/to/backup-file.tar.gz
```

### مراحل بازیابی

۱. **متوقف کردن سرویس‌های پنل**:
   ```bash
   sudo pasarguard down
   ```
۲. **اجرای دستور بازیابی**:
   ```bash
   sudo pasarguard restore /var/lib/pasarguard/backups/pasarguard-backup-YYYY-MM-DD.tar.gz
   ```
۳. **راه‌اندازی مجدد سرویس‌ها**:
   ```bash
   sudo pasarguard restart
   ```
۴. **بررسی وضعیت سیستم**:
   ```bash
   sudo pasarguard status
   ```

## 🛠️ راهنمای اسکریپت مدیریت (`pasarguard.sh`)

دستور `pasarguard` ابزارهای مدیریتی مختلفی را برای سرور شما فراهم می‌کند.

### دستورات اصلی سرویس

| دستور | توضیح |
| :--- | :--- |
| `pasarguard up` | اجرای تمام کانتینرهای داکر PasarGuard |
| `pasarguard down` | متوقف کردن تمام کانتینرهای داکر PasarGuard |
| `pasarguard restart` | راه‌اندازی مجدد تمام سرویس‌های PasarGuard |
| `pasarguard status` | نمایش وضعیت کانتینرها و مصرف منابع |
| `pasarguard logs` | مشاهده لاگ‌های زنده سیستم (`-f` برای دنبال کردن) |
| `pasarguard update` | بروزرسانی پنل PasarGuard به آخرین نسخه |
| `pasarguard tui` | باز کردن رابط متنی تعاملی کاربر (TUI) |

### منوی تعاملی TUI

برای استفاده آسان‌تر از طریق منوی متنی، محیط TUI را اجرا کنید:

```bash
sudo pasarguard tui
```
